# Fox Anatomy Reference Notes

Adapted from the upstream anatomy-note artifact under the included MIT license. These notes now guide a **red fox on a bicycle**, not a bird.

## Visual anchors

- A narrow, pointed muzzle and large pointed ears give the head its fox silhouette.
- A bushy tail with a pale tip is a useful red-fox cue.
- Slender legs contrast with the body and tail masses.
- Keep eye, nose and ear placement coherent with the selected viewing angle.
- Use the actual reference to set proportions; simplified circles and ovals are construction aids.

The [National Park Service's red-fox description](https://www.nps.gov/yose/learn/nature/redfox-biology.htm) supports the muzzle, ears, slender limbs and white-tipped bushy tail cues. It describes Sierra Nevada red foxes; it does not prescribe cartoon proportions or a riding pose.

## Composition notes for a bike pose

- Keep both wheels and the main frame triangle visible.
- Place the torso above the frame while showing support at the saddle.
- Let the hind paws land on the pedals, with different leg bends where the pose calls for them.
- Connect the forepaws to the handlebars if portraying active riding. A fox with no visible forelimbs does not yet establish that contact.
- Connect head, neck and torso as a continuous silhouette. Attach the tail clearly at the rear; a separated tail mass can appear to float.
- Keep ears, tail tip, feet and muzzle clear of confusing overlaps. Add small mechanical details only after rider/bike relationships read at thumbnail size.

## Reference usage

Inspect user-provided fox images when available. Otherwise inspect a useful fox profile, a head view and bicycle/rider geometry from sources with stated provenance. Record URLs, viewing angle and reuse terms before incorporating imagery. Read source content separately from interpreting photographs; a linked page is not evidence that every photograph was studied.

Use structure or tracing according to the user's requested original/faithful/corrected goal and applicable source-use constraints. State that a fox pedaling a bicycle is an invented pose; ordinary fox photographs inform anatomy, while riding references inform support and contact geometry.
