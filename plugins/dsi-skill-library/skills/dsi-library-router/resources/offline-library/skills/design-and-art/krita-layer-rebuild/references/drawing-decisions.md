# Drawing decisions

Read when a construction, material or corrective choice is uncertain. Source-based proposals and bounded native findings are identified separately. Tool behavior and material results need checks in the current job; a successful case does not validate every construction route.

| Condition | Decision and failure response | Attributed motivation / limit |
| --- | --- | --- |
| Detail hides wrong placement | Compare the owner's silhouette, landmarks and neighboring gaps. Hide its finish, repair scaffold, then restore local modeling. | [Prokopenko measurement](https://static.proko.com/static/course-lesson/measuring-techniques); [Mullins interview](https://www.ageofempires.com/news/celebrating-craig-mullins/). Exact-reference placement differs from invention/idealization. |
| Choice of gray or local-color start | Choose a route that exposes the reference's largest errors; retain regional color/light relationships rather than one universal sequence. | [Revoy workflow](https://www.davidrevoy.com/article949/overview-of-my-krita-digital-painting-workflow-end-2022). Creator merging is a production choice; delivery retains our semantic owners. |
| Wet-looking mark fails to blend or recolor | Test actual behavior separately; use a different local tool or rebuild owned marks if embedded color/edge behavior defeats the edit. | Miranda's [Digital Atelier guide](https://files.kde.org/krita/marketing/digital_atelier_reference_sheet.pdf), oilpp4–9/watercolorp18. Historical resource settings are not verified current presets. |
| Shape is correct but material generic | Compare mark scale, direction, interrupted edges and local value at output size; remove intrusive texture before adding evidenced marks. | [Vermeer paint application](https://www.nationalgallery.org.uk/research/publications/vermeer-and-technique/paint-application), Helen Howard's technical analysis. Regional physical material/drying are not digital brush settings. |
| Edit creates stale reflection or shadow | Track source item, receiving surface, view and overlap; rebuild the changed interaction and compare exposed receiver. | Robertson/Bertling [rendering sample](https://scottrobertsonworkshops.com/h2re/resources/h2Re_tracker.pdf), waterp222/weatheringp240. Semantic ownership/regeneration is our adaptation, not their demonstrated layer algorithm. |
| Ornament/grid distorts the supplied design | Inspect contour, counter and whole-layout spaces together; preserve source-specific asymmetry. | AbiFares/Samir [Al-Shaarani analysis](https://khattbooks.com/product/mouneer-al-shaarani-against-the-grain-exploring-the-scope-of-the-arabic-letter/), publicpreviewpp90–91. Authored analysis and static alternatives are not observed pen motion or Arabic-shaping validation. |
| Cleanup may erase intended marks | Identify target state and meaning first; faithful master retains it, corrected alternate documents interpretation. | [Langdon ambigram advice](https://www.johnlangdon.net/thoughts/advice-on-ambigrams/) contrasts contextually with expressive layout/painting practices. One designer's taste is not a universal reference-cleanup rule. |
| Later finish looks plausible but regresses | Compare saved candidates in a fixed frame, inspecting repaired and unchanged regions; restore the earlier best owner if needed. | Mullins's dead-end iterations and the project's observed B01 finish regression. More passes do not guarantee convergence to zero. |

For opaque objects, independently owned bases and clipped tones are useful candidates. For translucent/reflective objects, a fixed appearance layer may encode the receiving background; test movement on a different receiver before claiming independence. For connected lettering, semantic characters and visible components can share contours; map the shared dependencies rather than forcing arbitrary disconnected pieces.

## Diagnose before another finish pass

For boundary faults, identify contour position, jagged geometry, transition width or edge-color contamination separately. Repair misplaced geometry at its owner; adjust softness only where the reference has a soft transition. Inspect hard contours and hair/fur in separate regions so a broad smoothing pass cannot erase thin structures. Compare alpha and the isolated owner over light/dark backgrounds, then the actual composite. Check protected hairs, apertures and protrusions after each local repair; a cleaner edge that closes a correct gap is a regression. Scale feather/expansion choices to output dimensions instead of copying fixed tutorial pixels.

Sources: Colin Smith, [Select and Mask part 1](https://photoshopcafe.com/how-to-use-select-and-mask-in-photoshop-refine-edges-on-every-cutout/) and [part 2](https://photoshopcafe.com/select-and-mask-in-photoshop-free-masterclass-pt-2-fix-smooth-edges/). Their extraction controls motivate this native-boundary diagnosis; reference-pixel extraction is not the construction route.

Use an owner-specific diagnosis record: observed mismatch → responsible geometry/transition/mark → selected method → intended controls → fixed-frame before/after check. For a ceramic mug, distinguish body, front/back mouth, inner wall, handle, glaze marks and receiving shadow. Match the handle aperture and attachment tangents before glaze texture. Its hole exposes the real background; it is not a background-colored patch. A handle move carries its owned tones and requires attachment/contact repair, while the mug body and unrelated marks remain editable. This example combines the measured-construction and material guides; it does not prescribe the same hierarchy for every cup image.

Separate scaffold errors (occupied shape, gaps, overlap and major value/color regions) from transition errors (curvature, edge hardness, attached roots) and surface-mark errors (direction, scale, density). Name the affected owner and relation, then make one bounded correction and compare unchanged regions. Ebenebe’s [specific fingertip diagnosis](https://www.hipstersofthecoast.com/2021/07/behind-the-brush-ejiwa-edge-ebenebe/) motivates local diagnosis; [Feng Zhu’s tree lesson](https://fzdschool.com/blog_posts/sketching-101) distinguishes selective emphasis from stiff uniform branches. These sources supply conditions, not our acceptance thresholds.

An attached handle, branch, fold or ornamental rule needs a coherent opening and tangent after movement. Inspect the attachment at output size and in context; a filled angular wedge or clean payload hash does not prove the join. Light/refraction on a receiving surface needs a separate check. [Gill’s attributed stone-lettering appendix](https://www.gutenberg.org/cache/epub/47089/pg47089-images.html) and [eL Seed’s material collaboration](https://berengo.com/journal/glass-makes-you-rethink-a-conversation-with-el-seed/) motivate view/material dependence, not a universal digital repair.

Check distinguishing marks individually against the inventory before declaring finish. Give an identified mark its promised owner; disclose aggregate grain separately. If a requested detail cannot be located confidently, record it unfulfilled instead of substituting a nearby texture. [Winters’s mosaic construction](https://s3.amazonaws.com/cdn.johnnealbooks.com/downloads/bl8-4-winters.pdf) distinguishes internal spacing from a later outer border; applying that distinction to digital pattern ownership is our untested adaptation.

Physical preparation, exposure maps, print impressions, photographs and conservation overlays explain particular conditions. Keep analyst, collaborator, translator and later reviver attribution. Reproducing the visible supplied state is different from recovering original intent or hidden construction.

## Test a correction before extending it

Name the visible defect, responsible owner, proposed correction and protected neighboring content. Save a limited-region proof with its matching geometry, layer mapping and stroke settings. Inspect shape, light/shadow, mark direction and edge behavior at native size, then check the whole composition. Extend the procedure only when this actual result improves the named defect without a material regression. Use the user's quality target and budget; an accepted partial test is not a default stopping threshold for other work.

| Observed defect | Corrective decision |
| --- | --- |
| Fine strokes leave a swollen rim | Inspect coarse paint and actual brush footprints. Correct the source-observed boundary before adding detail; preserve legitimate fine protrusions and hidden continuation. |
| Cleanup exposes a hole or stationary fragment | Compare the source at that location. Correct visible-content ownership if it belongs to the object; reconstruct only genuinely unseen receiving content as inference. |
| A glaze has little visible effect | Inspect higher opaque detail, transferred paint and decorations. Put the correction on the appropriate top-owned paint or separate neutral receiver paint from decoration. |
| A bright spot is assigned to the wrong object | Follow occlusion and surrounding context to distinguish background emission, a surface accent and foreground material. Test the relevant packages separately. |
| Many new strokes improve color error but retain the wrong surface | Change geometry, volume or material treatment. Numerical color agreement does not establish brush language or perceived fidelity. |

These conditions were observed in the Revoy continuation: coarse eye/tool/hair rims, background-assigned temple hair, glazes blocked by opaque motif paint and a red light misassigned to a pointed tool. Regional improvements and failed treatments are documented in [tutorial-reproduction.md](tutorial-reproduction.md#attribution-and-bounded-evidence).

## Native-operation checks

Apply these when the available tool supports the operation; use its current schema and limits.

- Before cut/transfer or hierarchy changes, save a checkpoint and identify actual source/destination UUIDs, paint descendants and dependent masks. Transfer already constructed native paint, register its new owner and check placement, exposed receiver and unrelated content. Reconsider copied blur/effects when foreground and background roles differ.
- Test nonempty-group ordering on a separate small document before relying on it. On Krita6.0.0-beta1 `db05298`, remove/add reparenting destroyed descendants and adding an existing child could return success without moving it. Only the separately tested same-parent reorder preserved that case. Verify resulting order and every descendant; do not assume another build or tool has the same behavior.
- Batch strokes only after actual serial/batched comparison verifies color, size, opacity, overlap order and persistence for the relevant preset. Keep document, target layer, selection and structural state fixed through completion. Respect tool limits and finish queued work before switching context. Omit repeated full refreshes only after a separate projection-equivalence check, with an explicit checkpoint refresh.
- Treat an explicit empty-source transfer as a recorded no-op. Inspect its target and preserve completed prior cuts; resume from the known state. A timeout remains an unknown outcome and requires inspection before retrying.
- Inspect alpha, visible color and the composite separately when native cut/paste or masks change representation. Transparent RGB and tile serialization can differ without changing visible paint. Report those differences and bound projected filter fringe; preserve strict checks on unrelated visible content and geometry.
- Test intended path extent as well as brush diameter when a dab deposits too little paint. A short path is not guaranteed to produce a full-sized stamp. Keep pressure/taper claims within the actual tool's tested behavior.

The Revoy test exercised these bounded checks with Basic-5/Bristles-4, selected paint transfers and native save/reopen. They are operating checks, not permission to install adapters, raise limits or change user configuration.
