# Game development tool sources

Ten upstream software repositories are preserved under your GitHub account. The library provides focused, host-neutral integration skills for Codex and Claude, with pinned documentation and retained licenses. SDKs and editors are installed in the projects that need them, rather than treated as agent plugins.
