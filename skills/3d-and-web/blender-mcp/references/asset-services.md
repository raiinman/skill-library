# External asset services

Use an integration only when it exists in the discovered server and fits the user's requested assets. Poly Haven libraries, Sketchfab access, generated-asset services and API-key requirements vary with the bridge and account. Check current tool descriptions and service terms instead of inferring capability from an archived list.

Record each asset's source URL, license/attribution, downloaded files and any restrictions. Inspect import scale, orientation, hierarchy, materials and external texture paths. Request user sign-in when required without putting credentials in skill files, Git history or reports. Check available generation scope and costs before paid calls. Prefer the requested service and do not silently substitute another paid provider.

When creating world/material nodes, preserve unrelated graphs or work on a versioned copy. Configure the correct coordinate source for environment maps and appropriate color spaces for texture channels. Report generated/third-party provenance separately from native modeled geometry.
